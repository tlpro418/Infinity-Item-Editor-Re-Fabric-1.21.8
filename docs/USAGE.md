# Infinity Item Editor Re — 1.21.8 Fabric 详细使用教程

> 适用于本仓库构建的 `infinity_item_editor_re-1.21.8-Fabric-1.7.1-A.jar`。
> 这是一个**客户端** Mod：服务端通常不用装，但写入物品栏、复制装备等功能需要创造模式权限。

---

## 1. 安装

1. 安装 **Minecraft 1.21.8** + **Fabric Loader 0.20.1 或更新**。
2. 下载 [Fabric API](https://modrinth.com/mod/fabric-api) `0.136.1+1.21.8` 或更新，放进 `mods`。
3. 把 `infinity_item_editor_re-1.21.8-Fabric-1.7.1-A.jar` 放进 `mods`。
4. 启动游戏。`mods` 里应能看到 “Infinity Item Editor Re”。

> 只有客户端需要装；联机时服务器没有这个 Mod 也能用，但「保存到物品栏」等操作仍受服务器规则和创造模式权限限制。

---

## 2. 打开编辑器

| 操作 | 效果 |
| --- | --- |
| 手持物品按 **`U`** | 打开当前主手物品的编辑器 |
| 容器界面（箱子/背包等）中把鼠标悬停在**玩家物品栏槽位**上按 **`U`** | 编辑该槽位里的物品，并直接写回该槽位 |
| 主手为空按 `U` | 提示「请先手持一个物品」 |

按键可以在 **选项 → 控制 → 按键绑定 → Infinity Item Editor Re** 里改。

## 3. 界面构成（旧版布局）

```
┌───────────────────────────────────────────────────────────┐
│                       Infinity Editor                    │
│                       [物品预览图标]                       │
│  物品 ID: [ minecraft:diamond_sword ]                      │
│  数量:    [ 1 ]                                            │
│  附加值:  [ 0 ]                                            │
│  [NBT编辑][数据组件][NBT浏览器][JSON编辑]                   │
│                                        ┌───────────────┐   │
│   [物品选择器]                          │ 物品名称 [___][清除] │
│   [无法破坏]                            │ Lore  [______]  │
│   [自定义属性设定]                       │       [______]  │
│   [附魔] ...                            │       [隐藏标签] │
│                                        └───────────────┘   │
│  左侧：NBT / JSON 结构预览   中间：tooltip 预览             │
│                                                           │
│   [UI：旧版]        [关闭] [重置] [保存] [丢弃]             │
└───────────────────────────────────────────────────────────┘
```

要点：

- **物品 ID**：支持 `minecraft:` 命名空间与模组 ID；输入后即时校验，无效会提示。
- **数量**：1 ~ 32 位有符号整数上限；实际生效值仍受物品最大堆叠、服务器限制影响。
- **附加值 / Meta**：即耐久损耗值，范围由该物品最大耐久决定。
- **物品名称**：输入即写入；`清除` 恢复默认名称。
- **Lore**：逐行输入，最后一行留空会自动新增一行，行首 `X` 删除该行。
- **`隐藏标签`**：控制 tooltip 里哪些信息不显示（见 5.1）。
- **`UI：旧版/侧边栏`**：左下角按钮，随时切换布局并**立即写入配置**。侧边栏布局把常用按钮放左侧栏，适合宽屏。
- 窗口较小时编辑器会**自动等比缩放**并保持所有控件可点；调整窗口大小后布局会重新计算。

## 4. 保存、丢弃与复制命令

底部按钮（不同面板会略有变化）：

| 按钮 | 作用 |
| --- | --- |
| **保存** | 把当前编辑结果写回目标槽位（多人服需真实创造模式） |
| **Shift + 保存** | 改用 `/give` 命令给予物品（需要命令权限） |
| **丢弃** | 以物品形式丢出当前编辑结果（需创造模式） |
| **重置** | 清空当前面板相关的数据（不是清空整个物品） |
| **返回** | 回到上一层；若已在主面板则关闭编辑器 |
| **关闭** | 直接关闭编辑器（未保存的改动不影响原物品） |

### 保存的目标槽位规则

- 从**主手按 U** 打开：写回**当前选中的快捷栏槽位**。
- 从**容器里悬停玩家槽位按 U** 打开：写回**该槽位**。
- 单人游戏：直接改本地物品栏，并同步给内置服务端（立刻生效）。
- 多人游戏：需要**创造模式**，通过创造模式物品包写入；服务器若校验严格可能拒绝。

### 小技巧

- **Shift + 点击「丢弃」**：不丢物品，改为复制 `/give` 命令到剪贴板。
- 想保留原物品：改完后直接 `关闭`，原物品不受影响；或用「丢弃」拿一个新的。
- 想快速做一份命令：调好物品 → Shift+点「丢弃」→ 粘贴到聊天框。

## 5. 面板详解

专用面板按钮**只在当前物品适用时出现**（例如拿旗帜才有「旗帜」按钮）。

### 5.1 数据类

#### NBT编辑

- 直接编辑物品的 **SNBT**（旧版 NBT 视图），例如 `{display:{Name:'{"text":"剑"}'}}`。
- `更新 NBT` 应用；格式错误会给出提示；`重置` 清空。
- 注意：1.20.5+ 物品实际以**数据组件**存储，这里是「旧版 NBT ↔ 组件」的双向转换视图；不确定时优先用「数据组件」面板。

#### 数据组件（1.21+ 专用）

- 按分类浏览物品的全部 `minecraft:xxx` 组件，支持搜索、按模组分组。
- 每项显示当前值/默认值；支持类型化编辑：数字、布尔、枚举、注册表选项、RGB、原始 SNBT。
- 可双击进入编辑、移除组件、恢复默认值。
- 适合修改附魔、纹饰、容器内容、自定义数据等「新版物品数据」。

#### NBT 浏览器

- 只读的树状结构浏览：展开/折叠、滚动查看。
- 官方说明：功能尚未完成，不会直接修改物品。

#### JSON 编辑

- 以 JSON 形式查看/编辑物品（含组件结构），支持格式化、语法高亮、错误行列定位。
- `应用 JSON` 写回；有未应用修改时点「返回」会二次确认。

#### 隐藏标签

- 逐项开关 tooltip 显示：附魔、属性、无法破坏、可破坏方块（CanDestroy）、可放置方块（CanPlaceOn）、染色、纹饰、药水信息等。
- 对应 1.21 的 `minecraft:tooltip_display`：「隐藏」会把对应组件加入隐藏列表。

### 5.2 通用属性

| 面板 | 说明 |
| --- | --- |
| **无法破坏** | 主界面上的开关按钮，切换 `Unbreakable` |
| **附魔** | 搜索附魔；切换「显示可用 / 显示所有」；设置等级；单个添加、批量添加、移除、清空；条目多时按模组命名空间分组 |
| **药水** | 搜索药水效果；设置放大器（等级）、持续时间（秒）、是否显示粒子；添加/移除自定义效果 |
| **自定义属性** | 选择属性、数值、运算方式（`+` / `*` / `**`）、生效装备槽（任意/主手/副手/头/身/腿/脚）、「无限大」模式 |
| **颜色** | 皮革装备、药水、地图等的颜色：十六进制输入、RGB 滑条、随机颜色、染料色板 |

### 5.3 专用物品面板

- **告示牌**：编辑 4 行文本 + 第一行「点击命令」。
- **玩家头颅**：所有者名、UUID、纹理值、签名；`随机 UUID`、`清除所有者`。
- **盔甲架**：手臂、小型、隐形、底座、标记、重力、无敌等标签开关。
- **盔甲纹饰**（独立界面）：选材料与图案，实时预览（盔甲架/玩家/僵尸模型）；`应用当前纹饰`、`追加纹饰`（多层）、`移除最后一个`、`清空纹饰`。
- **烟花火箭 / 烟火之星**：飞行时间、爆炸形状（小球/大球/星形/苦力怕/爆裂）、颜色与淡出颜色、闪烁、轨迹；添加/移除/清空爆炸数据。
- **容器物品**（独立界面）：箱子/木桶/潜影盒等 27 格；选中槽位可编辑槽内物品 NBT、从「物品栏副本」取物品、`清空` 单格或 `全清`。
- **旗帜 / 盾牌**：搜索图案、底色、图案色；`添加图案`、`移除最后一层`、`清空图案`、`旗帜/盾牌互转`。
- **饰纹陶罐**：搜索陶片，分别设置正面/背面/左侧/右侧；应用、清空单面或全部。
- **刷怪蛋 / 刷怪箱**：搜索实体并应用；`同步刷怪蛋`（让蛋的实体与物品 ID 一致）、清除 `EntityTag`（蛋）/ `SpawnData`（刷怪箱）；编辑常用实体标签。
- **村民交易**（村民刷怪蛋）：`添加交易`、`移除`、`全清`；编辑价格 1 / 价格 2 / 产物、使用次数、最大次数、经验、价格倍率、特殊价格、需求；左键编辑、右键删除。
- **书本**：标题、作者、世代、解析状态；`签名成书` / `取消签名` / `重新签名`；逐页编辑、删除页面。
- **命令方块 / 命令方块矿车**：编辑内部命令；切换条件模式（受条件制约/不受制约）、激活模式（红石控制/保持开启）；`应用命令`、`重置`。

### 5.4 文本类

- **Lore 编辑**：`增加行列`、删除、上下移动、复制单行、`复制描述`、`复制工具提示文字`、`粘贴`。
- **Lore Painter**：用方块/阴影/空白字符绘制 tooltip 图案；可选颜色、调整画布行列、`比例`、`预览`、`插入` 到 Lore；绘制时可临时切换 GUI 缩放辅助对齐。

## 6. 物品选择器

主界面点 **`物品选择器`** 打开：

- 左侧切换来源：**Realm**（你保存的自定义物品）、**Void**（从聊天悬浮物/装备包收集的缓存）、**物品栏**（复制当前背包里的物品）。
- 顶部搜索框过滤，回车或点击搜索生效；`<--` / `-->` 翻页。
- 左键点击物品 → 写入当前编辑器（不会直接改背包）。

## 7. 创造模式标签页

创造模式物品栏里会多出 7 个标签页（可在配置里逐个关闭）：

| 标签页 | 内容 |
| --- | --- |
| **Infinity - Realm** | 你用 `G` 或编辑器保存的自定义物品 |
| **Infinity - Unavailable** | 命令方块、屏障、结构方块、刷怪笼、药水、附魔书等常规物品栏不直接提供的物品及变体 |
| **Infinity - Banners** | 旗帜、盾牌与图案变体 |
| **Infinity - Heads** | 玩家头颅与 MHF 系列头颅 |
| **Infinity - Thief** | 旧版行为的兼容辅助入口（聊天/装备包收集） |
| **Infinity - Fireworks** | 烟花火箭、烟火之星与预设变体 |
| **Infinity - Void** | 从聊天悬浮物、装备数据包收集到的物品缓存 |

> 这些标签页里的物品是「成品」：直接拖出来即可获得带 NBT/组件的物品。

## 8. 快捷键总表

| 按键 | 场景 | 功能 |
| --- | --- | --- |
| **`U`** | 手持物品 | 打开物品编辑器 |
| **`U`** | 容器界面 + 悬停玩家物品栏槽位 | 编辑该槽位并写回 |
| **`V`** | 准星指向方块/生物/玩家/盔甲架 | 复制目标为物品；**按住 Ctrl** 复制方块时带方块实体 NBT |
| **`G`** | 手持物品 / 容器内悬停物品 | 保存到 Realm 标签页 |
| **`Ctrl + C`** | 容器界面悬停物品 | 复制该物品的 `/give` 命令 |
| **`Ctrl + V`** | 容器界面悬停玩家物品栏槽位（创造模式） | 把剪贴板里的 `/give` 物品粘贴到该槽位 |
| **`Shift` + 点击「丢弃」** | 编辑器内 | 复制 `/give` 命令 |

复制方块/生物时：方块会生成对应物品；生物/玩家/盔甲架会把目标装备复制到你的对应装备槽位。

## 8.5 实验性：去除服务器标记

服务器原生物品通常带有 `custom_data` 追踪字段（如 `WLProtocol_*`、`display`、UUID），在单人改完带回服务器会被识别并还原。

- 在 `config/infinity_item_editor_re.json` 中设置 `"stripServerTags": true`（或启动参数 `-Dinfinity_item_editor_re.stripServerTags=true`）；
- 保存时会剥离这些字段，物品会以“无标记的新物品”发给服务器；
- **风险**：部分服务器会直接删除非法物品，默认关闭，请先备份/在测试物品上试。

## 9. 配置

配置文件（**不是 toml**）：

```text
.minecraft/config/infinity_item_editor_re.json
```

字段：

```json
{
  "itemGuiMode": "LEGACY",          // LEGACY 旧版布局 / SIDEBAR 侧边栏
  "voidTab": true,                  // 显示 Infinity - Void 标签页
  "voidAddNotification": false,     // 新 Void 条目提示
  "voidTabHideHeads": false,        // Void 页隐藏玩家头颅
  "unavailableTab": true,
  "bannerTab": true,
  "headTab": true,
  "thiefTab": true,
  "fireworkTab": true
}
```

- 改完保存后重启游戏生效（`itemGuiMode` 也可在编辑器里用 `UI` 按钮即时切换并写回）。
- 关闭某个标签页可减少创造物品栏加载量。

## 10. 数据文件与备份

```text
.minecraft/infinity-data/realm.nbt    # Realm 标签页保存的物品
.minecraft/infinity-data/void/        # Void 缓存（按玩家/来源分文件）
```

- 旧版的 `.minecraft/infinity-data/infinity.nbt` 会自动迁移为 `realm.nbt`。
- 换整合包/换电脑时，复制整个 `infinity-data` 目录即可带走自定义物品。
- 建议定期备份 `realm.nbt`；它是 NBT 文件，损坏后编辑器里的 Realm 列表会变空。

## 11. 限制、报错与排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 「应用到物品栏需要处于创造模式」 | 多人服务器写物品栏需要创造模式；单人一般不受限 |
| 数量改大后实际变小 | 受物品最大堆叠/服务器逻辑限制，超出部分可能被钳制 |
| 「无效物品 ID」 | ID 拼写错误或该模组未安装；先确认注册名（如 `minecraft:stick`） |
| 「NBT 无效 / JSON 无效」 | 语法错误；JSON 面板会给出行列位置，NBT 面板给错误摘要 |
| 界面元素错位/太小 | 调整窗口大小或 GUI 缩放；编辑器会自动等比缩放并重排 |
| 服务器拒绝写入 | 服务器插件/反作弊可能拦截创造模式物品包；这属于服务器限制 |
| 找不到某个面板按钮 | 该面板只对适用物品显示（例如「旗帜」只对旗帜/盾牌出现） |

**关于 NBT 与组件**：1.21 起物品数据是「数据组件」。本 Mod 的 NBT 面板显示的是转换后的旧版 NBT 视图；保存时会转回组件。若某个修改在 NBT 面板里不生效，改用「数据组件」面板直接改对应组件。

## 12. 使用建议与合规提醒

- 这是**创造模式工具**：请只在允许的服务器/存档使用，多人服务器滥用可能被封禁。
- 编辑出的物品仍受服务端校验；「看起来能用」不等于服务器一定接受。
- 做复杂物品前先 `G` 存一份到 Realm，改坏了可以随时取回。
- 常用组合：`U` 改属性 → `UI` 切侧边栏 → 保存；或 `V` 复制目标 → `U` 微调 → Shift+「丢弃」拿 `/give` 命令分享。
